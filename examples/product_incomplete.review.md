# Проверка генерации с неполными данными

Из входа второго товара удалён производитель.
Степень защиты заменена строкой из пробелов, масса — null.

## Результат

- Получен status: draft.
- Производитель, степень защиты и масса не восстановлены моделью.
- Пустые характеристики отображены как «данных нет».
- Все три пропуска перечислены в missing_fields.
- Модель сформировала вопросы для уточнения данных.
- Ранее замеченные бытовое применение и формулировки
  «дистанционный/локальный запуск» в этом ответе отсутствуют.

## Замечания

В commercial_block количество включений прибора интерпретировано
как частота стартов оборудования. Это не подтверждено входом.

Последнее предложение может создавать впечатление обязательности
внешнего датчика, хотя во входе предусмотрен запуск отсчёта
при подаче питания.

## Вывод

Обработка пустых полей работает в проверенном сценарии.
Проверка схемы не выявляет смысловые искажения свободного текста.
Перед публикацией необходима редакторская сверка с источником.

Сохранён фактический ответ модели без ручного исправления.
